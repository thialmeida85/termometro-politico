# TruthMeter AI — Extensão Chrome

## Instalação

1. Extraia o ZIP para uma pasta permanente.
2. Abra `chrome://extensions` no Chrome.
3. Ative **Modo do desenvolvedor**.
4. Clique em **Carregar sem compactação**.
5. Selecione a pasta extraída.
6. Abra ou atualize um vídeo no YouTube.

## Arquivos incluídos

- `manifest.json`: configuração Manifest V3.
- `content.js`: HUD e interação com o player.
- `styles.css`: layout visual sobreposto ao vídeo.
- `background.js`: ações do botão da extensão.
- `demo-claims.json`: dados demonstrativos usados pelo protótipo.
- `icons/`: ícones usados pelo Chrome.

Esta versão ainda apresenta dados demonstrativos no HUD. O backend vocal do Render fica separado e não deve ser colocado dentro deste ZIP.
